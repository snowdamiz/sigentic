Savorly

Good recipes, and a sous-chef to cook them with.

A cooking community for finding recipes, sharing your own and actually cooking them. The sous-chef is built into every screen: ask it by text, voice or photo, or talk to it hands-free with flour on your hands.

Visit savorly.cooking Source
  • Cook mode with step timers and spoken steps.
  • Cook-tested times from people who made it.
  • One timeline for a whole meal of dishes.
  • Shared planner, pantry and grocery list.

CookingLiveStage: Beta

Live on the web. The iPhone and Android apps are in testing ahead of their App Store and Google Play release.

Morse

Private messaging, kept honest.

Pick a username and start talking: no phone number, no email, no address book. Only the people in a chat can read it, not even us, and independent witnesses check every key the server hands out.

Join the waitlist Source
  • End-to-end encrypted, file names included.
  • No phone number or address book.
  • Disappearing messages on any chat.
  • Protocol written in Mesh, our language.

Private messagingIn developmentStage: Prototype

Early desktop builds for Mac and Windows. iPhone and Android share the same encrypted core and are in development, with no production-security claim yet.

Mesh

Write a server. Ship a fleet.

A statically typed, actor-based language with Elixir-style syntax. It infers your types, compiles to a single native binary through LLVM, and builds clustering into the runtime: mark the work that can run anywhere, and Mesh handles placement, routing and failover.

Visit meshlang.dev Source
  • Typed actors, supervisors and channels.
  • Hindley-Milner type inference.
  • HTTP, WebSockets and Postgres built in.
  • Formatter, tests, REPL and language server.

Programming languagev0.1.8Stage: Beta

Installable today. The language and package format can still change before 1.0.

Incant

The game engine you can talk to.

Model, script and ship 2D and 3D games in one application. Work by hand, in TypeScript, or by asking the agent. Every change lands as a command you can read, test and undo.

See the project Source
  • One undoable history for every edit.
  • Plain-text, diffable project files.
  • The agent play-tests and shows proof.
  • Bring your own OpenAI account.

Game engineIn developmentStage: Prototype

Rendering, physics, scripting, input and game saves are coming together in the first engine phase. No public release yet.

Mixer

Write Swift. Ship both.

Build iPhone and Android apps from one Swift codebase. You write the screens and state once, and Mixer draws them with each platform’s own native controls. It’s designed to send compatible fixes as signed updates, without waiting on a new store build.

Read the plan Source
  • Native controls on iPhone and Android.
  • One CLI to create, test and build both.
  • Signed updates that fall back safely.
  • Compatibility report for existing Swift apps.

Mobile platformIn developmentStage: Prototype

A Swift app already runs with native controls on a physical Pixel, and the CLI builds iOS Simulator apps and unsigned Android APKs. Signed updates, app-store builds and the hosted release service are in progress. No public release yet.

Most software tries to be everything for everyone.

We think the best tools do one thing with uncommon care. So we pick a corner of everyday life (the stovetop, the group chat, the server, the game editor) and build the software it deserves. Then we do it again.

Principles

  • Private by default. We collect the minimum, encrypt what we can, and never sell your data.
  • One job, done well. If a feature doesn’t earn its place, it doesn’t ship.
  • Respect for attention. No dark patterns, no infinite feeds, no guilt-trip notifications.
  • Made for everyone. Screen readers, dynamic type, contrast and reduced motion are designed in from day one.
  • Built to last. Honest business models, so the software you rely on is still here years from now.
  • Developed in public. Every project’s code is on GitHub.
