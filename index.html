No. 01 · CookingLive

Savorly

Good recipes, and a sous-chef to cook them with.

A cooking community for finding recipes, sharing your own and actually cooking them. The sous-chef is built into every screen: ask it by text, voice or photo, or talk to it hands-free with flour on your hands.

  1. Cook mode with step timers and spoken steps
  2. Cook-tested times from people who made it
  3. One timeline for a whole meal of dishes
  4. Shared planner, pantry and grocery list

No. 02 · Private messagingIn development

Morse

Private messaging, kept honest.

Pick a username and start talking: no phone number, no email, no address book. Only the people in a chat can read it, not even us, and independent witnesses check every key the server hands out.

  1. End-to-end encrypted, file names included
  2. No phone number or address book
  3. Disappearing messages on any chat
  4. Protocol written in Mesh, our language

No. 03 · Programming languagev0.1.8

Mesh

Write a server. Ship a fleet.

A statically typed, actor-based language with Elixir-style syntax. It infers your types, compiles to a single native binary through LLVM, and builds clustering into the runtime: mark the work that can run anywhere, and Mesh handles placement, routing and failover.

Pl. 03 · Mesh, a typed actor

  1. Typed actors, supervisors and channels
  2. Hindley–Milner type inference
  3. HTTP, WebSockets and Postgres built in
  4. Formatter, tests, REPL and language server

Install

$curl -sSf https://meshlang.dev/install.sh | sh

macOS · Linux · Windows

Visit meshlang.dev Source

No. 04 · Game engineIn development

Incant

The game engine you can talk to.

Model, script and ship 2D and 3D games in one application. Work by hand, in TypeScript, or by asking the agent. Every change lands as a command you can read, test and undo.

  1. One undoable history for every edit
  2. Plain-text, diffable project files
  3. The agent play-tests and shows proof
  4. Bring your own OpenAI account

No. 05 · Mobile platformIn development

Mixer

Write Swift. Ship both.

Build iPhone and Android apps from one Swift codebase. You write the screens and state once, and Mixer draws them with each platform’s own native controls. It’s designed to send compatible fixes as signed updates, without waiting on a new store build.

  1. Native controls on iPhone and Android
  2. One CLI to create, test and build both
  3. Signed updates that fall back safely
  4. Compatibility report for existing Swift apps

03Approach

From spark to shipped.

A repeatable process for turning everyday friction into software people genuinely love to use.

  1. 1

    Notice

    Every product starts with real friction: the recipe you can’t scroll with flour on your hands, the chat you’d rather nobody else could read.

  2. 2

    Invent

    We prototype fast and test honestly. Most ideas don’t survive the bench — the ones that do have earned the right to be built.

  3. 3

    Build

    Native-quality engineering with privacy, performance and accessibility designed in from the very first commit — never bolted on later.

  4. 4

    Deploy & tend

    Launch day is the starting line. We ship, listen, measure what matters and keep making it better for as long as people rely on it.

04Principles

What we won’t compromise on.

Fields change from product to product. These don’t. They’re the reason you can trust anything with our name on it.

  1. 1

    Private by default

    We collect the minimum, encrypt what we can, and never sell your data. Not to advertisers. Not to anyone.

  2. 2

    Craft is the feature

    The details are the product. We sweat every transition, every word and every millisecond.

  3. 3

    One job, done beautifully

    Focused tools beat bloated suites. If a feature doesn’t earn its place, it doesn’t ship.

  4. 4

    Respect for attention

    No dark patterns, no infinite feeds, no guilt-trip notifications. Your time is yours.

  5. 5

    Made for everyone

    Dynamic type, screen readers, contrast and reduced motion are part of the design from day one, not an afterthought.

  6. 6

    Built to last

    Honest, sustainable business models — so the apps you depend on are still here, and still good, years from now.
