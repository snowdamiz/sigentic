Morse

Private messaging, kept honest.

Pick a username and start talking. No phone number or address book, only the people in a chat can read it, and independent witnesses check every key the server hands out.

Mesh

Write a server. Ship a fleet.

A statically typed, actor-based language with Elixir-style syntax. It compiles to one native binary and builds clustering into the runtime, so Mesh handles placement, routing and failover.

Programming language · v0.1.8 · Beta

Visit meshlang.dev Source

Incant

The game engine you can talk to.

Model, script and ship 2D and 3D games by hand, in TypeScript, or by asking the agent. Every change lands as a command you can read, test and undo.

Game engine · In development · Prototype

See the project Source

Mixer

About

Most software tries to be everything for everyone. We think the best tools do one thing with uncommon care.

So we pick a corner of everyday life (the stovetop, the group chat, the server, the game editor) and build the software it deserves. Then we do it again.

Principles

  • Private by default.

    We collect the minimum, encrypt what we can, and never sell your data.

  • One job, done well.

    If a feature doesn’t earn its place, it doesn’t ship.

  • Respect for attention.

    No dark patterns, no infinite feeds, no guilt-trip notifications.

  • Made for everyone.

    Screen readers, dynamic type, contrast and reduced motion are designed in from day one.

  • Built to last.

    Honest business models, so the software you rely on is still here years from now.

  • Developed in public.

    Every project’s code is on GitHub.
